## MODIFIED Requirements

### Requirement: Обязательный состав блока бейджей
`README.md` SHALL содержать блок бейджей, показывающий шесть характеристик репозитория: базовый
Claude-образ вместе с его тегом, версию Python, версию OpenSpec, версию uv, версию kit'а и лицензию.
Блок MUST располагаться между заголовком файла и назначением.

Блок SHALL оставаться единственным местом `README.md`, где показываются номера версий: перечень
состава инструментов версий не приводит и ссылается на этот блок, поэтому второй копии значений
в документе не возникает.

Абсолютные URL, допускаемые в блоке по
[DOC-015](../../../rules/documentation-rules.md#ссылки-doc-015), MUST NOT считаться единственным
исключением этого правила в `README.md`: второе место — названия пунктов перечня состава
инструментов, где ссылка ведёт на внешний источник инструмента. Размещение самого блока при этом
не меняется.

#### Scenario: Читатель открывает README
- **WHEN** читатель открывает `README.md` и видит первый экран
- **THEN** ему видны базовый образ с тегом, версии Python, OpenSpec и uv, версия kit'а и лицензия —
  без перехода в `Dockerfile`, `VERSION` или `LICENSE`

#### Scenario: Блок размещён после назначения
- **WHEN** блок бейджей размещён ниже назначения или в другом разделе `README.md`
- **THEN** размещение считается нарушением: для самого блока исключение DOC-015 действует только
  между заголовком и назначением

#### Scenario: Версия понадобилась в другом разделе
- **WHEN** раздел `README.md` говорит об инструменте, у которого есть бейдж версии
- **THEN** раздел ссылается на блок бейджей или на файл-источник, а номер версии в свой текст
  не выносит
