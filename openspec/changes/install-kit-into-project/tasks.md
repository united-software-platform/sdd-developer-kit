      предварительного просмотра, неинтерактивный режим с разрешением на перезапись) — проверить,

- [x] 2.2 Реализовать проверку целевого каталога (существует, доступен на запись) с завершением до

      один файл не создан
- [x] 2.3 Задать явный список путей поставки (`Dockerfile`, `docker-compose.yml`, `Makefile`,

      `openspec/config.yaml`, `tools/host-runner/`, `docs/sdd-kit.md`) и прервать установку ошибкой,
      если путь из списка отсутствует в клоне kit'а — проверить временным удалением пути из копии клона
- [x] 2.4 Реализовать построение плана: разнести файлы поставки на создаваемые, безопасно
      перезаписываемые (совпадает контрольная сумма из манифеста) и конфликтующие — проверить, что
      первый проход не изменяет целевой каталог (сверка содержимого до и после)
- [x] 2.5 Реализовать режим предварительного просмотра: вывести полный план и завершиться без
      записи — проверить, что целевой каталог после запуска не изменился

- [x] 3.2 Реализовать отказ: при отрицательном ответе завершиться без записи и без удалений —

- [x] 3.4 Реализовать копирование файлов поставки по плану с сохранением относительных путей —
