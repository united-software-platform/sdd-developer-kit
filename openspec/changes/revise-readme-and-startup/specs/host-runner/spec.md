## MODIFIED Requirements

### Requirement: Белый список целей ограничен Makefile репозитория
Host-runner SHALL принимать к выполнению только цели `make` из белого списка, каждая из которых
существует в `Makefile` этого репозитория: `init`, `openspec-init`, `help`.
Запрос любой другой цели MUST завершаться отказом с кодом `400` и без выполнения `make`.

Белый список MUST быть подмножеством целей `Makefile`, а не совпадать с ними: цель, требующая
терминала для взаимодействия с пользователем, MUST NOT входить в белый список. Такая цель не
завершилась бы сама и удерживала бы host-runner до предела времени выполнения, блокируя все
последующие запросы.

Цель сборки образа MUST NOT входить в белый список: образ собирается пайплайном репозитория kit'а
и загружается из реестра, поэтому такой цели в `Makefile` нет — а несуществующая цель завершилась бы
ошибкой `make`, неотличимой для агента от отказа окружения.

Управление контейнером агента MUST NOT быть доступно через host-runner: целей запуска, остановки
и входа в контейнер в `Makefile` нет, а рабочая сессия агента открывается эфемерным контейнером,
которым владеет пользователь на хосте, — перезапустить сессию из неё самой невозможно по построению.

#### Scenario: Разрешённая цель
- **WHEN** агент запрашивает цель `init`
- **THEN** host-runner выполняет `make init` в корне репозитория и возвращает код возврата и вывод

#### Scenario: Цель вне белого списка
- **WHEN** агент запрашивает цель, отсутствующую в `Makefile` репозитория (например `authors` или
  `restart`)
- **THEN** host-runner отклоняет запрос с кодом `400`, не запуская `make`, и перечисляет разрешённые
  цели в ответе

#### Scenario: Интерактивная цель Makefile
- **WHEN** агент запрашивает цель, требующую терминала для взаимодействия с пользователем
- **THEN** host-runner отклоняет запрос с кодом `400`, не запуская `make`, и не удерживает
  соединение до предела времени выполнения

#### Scenario: Запрос управления контейнером
- **WHEN** агент запрашивает цель запуска или остановки контейнера (`up`, `down`)
- **THEN** host-runner отклоняет запрос с кодом `400`, не запуская `make`, и перечисляет разрешённые
  цели в ответе

#### Scenario: Обновление инструментов SDD из контейнера
- **WHEN** агент запрашивает цель `openspec-init`
- **THEN** host-runner выполняет `make openspec-init` в корне репозитория и возвращает код возврата
  и вывод, не требуя от агента прохождения хостовой части подготовки проекта

#### Scenario: Запрос сборки образа
- **WHEN** агент запрашивает цель `build`
- **THEN** host-runner отклоняет запрос с кодом `400`, не запуская `make`, и перечисляет разрешённые
  цели в ответе
