- [x] 1.1 Создать `tools/make-lint/check.sh` со скелетом по образцу `tools/version/check.sh`:
      заголовочный комментарий о назначении, `set -eu`, `usage()` на русском, `die()`, разбор ключей
      `--max-lines`, `--makefile`, `-h/--help`, коды возврата `0/1/2`. Проверка: `sh tools/make-lint/check.sh --help`
      печатает справку и завершается с кодом `0`, неизвестный ключ — с кодом `2`
- [x] 1.2 Реализовать валидацию значения `--max-lines`: целое положительное, иначе ошибка вызова.
      Проверка: вызовы с `0`, `-5` и `abc` завершаются кодом `2` и называют полученное значение,
      файл при этом не читается
- [x] 1.3 Реализовать разбор строк целей на `awk`: строка не начинается с табуляции, содержит `:` вне
      рецепта, не является присваиванием (`=`, `:=`, `::=`, `+=`, `?=`), имя не начинается с точки.
      Проверка: на текущем `Makefile` найдены ровно `help`, `init`, `init-host`, `openspec-init`,
      `build`, `up`, `down`, `shell`; `.PHONY` и `.DEFAULT_GOAL` в список не попали
- [x] 1.4 Реализовать определение границ секции: подъём вверх по непрерывному блоку комментария до
      пустой строки, спуск вниз по строкам рецепта и комментариям между ними, без хвостовых пустых
      строк. Проверка: измеренные объёмы на текущем `Makefile` равны `help` — 8, `init` — 7,
      `init-host` — 61, `openspec-init` — 19, `build`/`up`/`down` — 2, `shell` — 15
- [x] 1.5 Реализовать сравнение с пределом и отчёт: строка `Makefile:<строка>: <цель> — <объём> строк
      при пределе <предел>` на каждое нарушение, перечисляются все. Проверка: `sh tools/make-lint/check.sh --max-lines 10`
      на текущем `Makefile` выводит три нарушения (`init-host`, `openspec-init`, `shell`) и завершается кодом `1`
- [x] 1.6 Реализовать успешный вывод: действующий предел и число проверенных секций. Проверка:
      `sh tools/make-lint/check.sh --max-lines 100` завершается кодом `0` и печатает предел `100`
- [x] 1.7 Реализовать умолчание предела `30` одной переменной в начале скрипта и его подстановку при
      отсутствии ключа. Проверка: вызов без ключей печатает предел `30`
- [x] 1.8 Реализовать обработку недоступного файла и ключ `--makefile`. Проверка: вызов с путём к
      несуществующему файлу завершается кодом `2` и называет путь; вызов с `--makefile` на подготовленном
      временном make-файле измеряет именно его
