## REMOVED Requirements

### Requirement: Ссылочная целостность документации проверяется автоматически
**Reason**: Проверка не устранила ни одного дефекта: чистку правил от следов чужой методологии
выполнили руками до её появления, а все находки первого прогона оказались ложными — примеры формата
в блоках кода и цвет бейджа, из-за которых пришлось завести три исключения. Инструмент остался
страховкой от повторения, которую нужно сопровождать и объяснять, при том что набор не заводит
проверок «на случай, если понадобится».

Норма ссылочной целостности сохраняется требованием «Правила ссылаются только на существующие
артефакты набора»: удаляется её машинный контроль, а не сама норма.

**Migration**: Проверка выполняется автором изменения при правке документации — так же, как она
выполнялась до появления инструмента. Если понадобится вернуть автоматический контроль, скрипт
и пайплайн достаются из истории репозитория целиком, вместе с обоснованием исключений:

```bash
git show 873778e:tools/docs-lint/check.sh > tools/docs-lint/check.sh
git show 873778e:.github/workflows/docs-lint.yml > .github/workflows/docs-lint.yml
```

Возврат потребует нового изменения: требование, удалённое здесь, придётся вернуть в способность
`repo-rules`.
