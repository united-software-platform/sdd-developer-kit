## MODIFIED Requirements

### Requirement: Значения бейджей связаны с источниками в репозитории
Значения бейджей базового образа, Python, OpenSpec, uv и версии kit'а SHALL вычисляться из файлов
репозитория — `Dockerfile` для образа и трёх версий инструментов, `VERSION` для версии kit'а.
Эти значения MUST NOT дублироваться в `README.md` вручную: изменение версии в источнике меняет
бейдж без правки `README.md`.

Бейдж версии kit'а SHALL показывать номер с префиксом `v` — единообразно с git-тегом релиза, которому
эта версия соответствует. Префикс SHALL добавляться при отображении бейджа: файл `VERSION` остаётся
источником значения и хранит номер без префикса, поэтому смена версии MUST NOT требовать правки
`README.md`.

#### Scenario: Обновление версии инструмента
- **WHEN** в `Dockerfile` меняется значение `ARG PYTHON_VERSION`, `ARG OPENSPEC_VERSION` или
  `ARG UV_VERSION`
- **THEN** соответствующий бейдж показывает новое значение, а `README.md` не редактируется

#### Scenario: Смена базового образа
- **WHEN** в `Dockerfile` меняется строка `FROM` базового Claude-образа или её тег
- **THEN** бейдж образа показывает новое имя образа вместе с новым тегом

#### Scenario: Источник значения переименован
- **WHEN** `ARG` в `Dockerfile` переименован или удалён и значение перестаёт извлекаться
- **THEN** бейдж отображается как ошибка, а не как устаревшее значение — расхождение видно, а не
  замаскировано

#### Scenario: Инкрементация версии kit'а
- **WHEN** файл `VERSION` меняется с `1.0.0` на `1.1.0`
- **THEN** бейдж версии показывает `v1.1.0`, совпадая с меткой тега `v1.1.0`, а `README.md` не
  редактируется
